Northwind Web Engineering Programme

A two-year, hands-on study programme for future web developers.

About the programme

The Northwind Web Engineering Programme teaches how the web really works, from HTML and CSS in the browser all the way to servers written in Node.js. Students build a real project every term and present it to a small panel of industry mentors.
